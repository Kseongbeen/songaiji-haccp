# 한우 출하노트 — 작업 인계 요약 (2026-09-25, v8 기준)

## 1. 공모전
- 2026년 한국식품안전관리인증원 공공데이터 분석·활용 경진대회, **분석 부문**
- 마감 2026-09-30, A4 15쪽 이내(표지·목차·부록 포함), HWP/HWPX/DOCX/PDF
- 배점: 실현가능성 40 / 정책 관련성 20 / 데이터 활용성 20 / 완성도 20
- 시상 6점(최우수 150만 원). 1차 서면평가 → 2차 발표평가

## 2. 아이디어 핵심
- 제목: 「한우 출하노트」 — 약 기록 연계와 인공지능으로 농장 HACCP 기록을 자동화하고, 그 기록으로 휴약 확인과 출하 판단을 돕는 한우 스마트HACCP 모델
- **문제 정의(두 축 고정)**
  1. 평가표 항목마다 손으로 기록해야 함 (전산 체계 없음)
  2. 인증해도 등급판정 세부기준에 항목이 없어 소 값이 오르지 않음
  - 결과: 한우 농장 HACCP 인증률 2.5%, 스마트HACCP 농장 등록 0건
- **해결**
  - A. 위생·안전: 전자처방·판매기록 연계로 약 기록 자동, 출하 전 휴약 자동 점검
  - B. 보상: HACCP 기록 전체 + 이력제 혈통·월령 → 소별 예상 등급·출하 시기·월간 농장 성적표
- **차별성**: "최초 개발"을 주장하지 않음. 국내 한우 환경에서 수집 → 확인 → 안전관리 → 출하 판단을 하나로 연결하는 범위가 차별성
- **인공지능 적용은 세 곳만**
  - 약 포장 인식(1단계), 출하 판단(2단계), 기록 이상 탐지(3단계)
  - 제외: 사진 위생 점검, 규정 문답 챗봇, 성적표 자동 해설, 음성 기록 (제외 이유도 기획서에 명시)

## 5. 검증된 핵심 수치
- 한우 인증률 2.5% (72,389곳 중 1,835곳), 50마리 이상 기준 상한 8.9%
- 축종별 인증률: 닭 61.4%, 돼지 24.2%, 오리 20.9%, 젖소 11.8%, 한우 2.5%
- 스마트HACCP 농장 등록 0건, 기술지원 2,719건 중 농장 1건
- 스마트HACCP 중요관리점 668개 중 603개(90.3%)가 기계 계측 항목
- 컨설팅 예산 2019년 28억 원 → 2024년 10억 1,500만 원(64% 감소), 한우 169~330곳이 한계
- HACCP 적용 애로 1순위가 기록 작성 43.30% (남인식 외 2014, 산란계 15개소)
- 최적 출하월령: 도체형질 최고 34~35개월 vs 생산비 반영 27.22개월 (이승웅·이지웅 2024, 거세우 226,304두)
- 한우 근내지방도 예측 상관 0.64 (Shahinfar 외 2020, 3,989두) — 정확도 과장 금지 근거
- 일본 흑소 농장: 5등급 36.5% → 66~78%, 호흡기 치료 78두 → 28~39두 (Akaike 외 2023, 비교 농장 없음)
- 거세우 1등급 이상 출현율 91.5%(암소 65.1%, 수소 5.5%), 마블링 유전율 0.22~0.56

## 6. 데이터 연계
- **즉시 가능**: 축산물이력제(공개 API·축산 마이데이터), 인증원 HACCP 인증업체정보, 기상청 ASOS 일자료
- **협의 필요**: eVET 전자처방 (공개 API 없음, 농장주 본인 조회 서비스는 운영 중)
- **미비**: 처방 없이 판매되는 약(판매자 보고 의무 없음), 제품별 휴약기간(공개 데이터 없음), 동물용의약품 포장 바코드 표준 여부

## 7. 정해 둔 방침
- 기획서는 **개조식, 반말체**("~함 / ~임 / ~없음"). 사용자와의 대화는 존댓말
- 뺀 것: 시연 시나리오 표(발표 3~5분), 가상 인물 서사, 음성 기록·사진 점검·문답 챗봇 화면
- 화면의 숫자·농장명·인물·제품명·전화번호는 모두 가상 자료라고 명시
- 예측 설계 원칙: 도축 후 정보 입력 금지, 농장·시간 분리 검증, '치료 없음'과 '기록이 없음'을 구분, 약품 사용의 인과 효과로 해석 금지
- 구매·처방과 실제 투약을 구분. 외부 기록은 초안으로 불러오고 농가 확인 후 확정, 불완전 기록은 '확인 필요' 상태

## 8. 남은 일
1. **쪽수 확인** — v3 기준 16쪽이었고 v8은 더 늘었을 수 있음. 한글 COM 자동 변환이 멈춰 자동 집계 불가
2. 스크립트(`42_기획서_HWPX.py`)는 v4 상태 — v8의 손편집이 반영돼 있지 않음. 다시 돌리면 v8 수정분이 사라지므로, 이후 기획서는 한글에서 v8을 직접 편집할 것
3. 인증원 대회 역대 수상작 이름은 비공개 — haccp.or.kr 공지사항 직접 확인 필요
4. 발표 초안 v6를 최종 구조(개조식·인공지능 범위 축소)에 맞춰 갱신할지 결정
