## 3. 새로 알게 된 사실 (해결 방안에 반영)

- **축사로**(국립축산과학원)에 이미 동물약품 구매·사용, 수의사 처방관리 기록 칸이 있고 이력제 정보를 자동으로 불러옴 (2023) → 해결 A를 '새 앱'에서 '축사로 연계'로 바꿈
- 수의사 처방전에는 농장명·동물 종류·약·수량이 들어가지만, **소 이력번호는 필수가 아님**(같은 축사는 한 처방전으로 가능) → '소 선택 한 번'이 필요한 이유
- **약국은 주사용 항생제·생물학적 제제를 뺀 처방대상 약을 처방전 없이 팔 수 있음**(약사법 제85조⑦) → 전자처방만으로는 빠지는 기록이 있음
- 판매기록 규정(취급규칙 제22조③)은 '판매일자·제품명·수량·용도·구매자 등, 1년 이상 보존'만 정하고 **서식·전산 제출·농장번호는 정하지 않음**
- 휴약기간 과태료는 **수의사 처방에 따라 사용한 경우 사용 기준 적용이 빠짐**(약사법 제85조③ 단서) → 슬라이드에 예외를 적음
- HACCP 인증 혜택(법에 적힌 것): 인증 명칭 사용, 기술·교육 지원, 평가 우수 시 조사 면제 등 → v4의 '점검 면제' 언급은 근거가 있었음. v6은 '소 값에 반영되는 장치는 없음'으로 표현
- 등급판정 세부기준(고시 제2026-80호) 육질 항목에 HACCP 인증 여부 없음 [원문]
